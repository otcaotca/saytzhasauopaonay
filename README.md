# saytzhasauopaonay

AI арқылы сайт жасайтын алғашқы MVP.

## Іске қосу
1. `backend` ішіне кір:
   `npm install`
2. `.env.example` файлын `.env` деп көшір.
3. `.env` ішіне OpenAI API key жаз.
4. `npm start`
5. Браузерде `http://localhost:3000` аш.

## Не істейді
- AI-ға қазақша тапсырма жіберу
- HTML/CSS/JS сайт генерациялау
- Preview ішінде көрсету
- Publish басқанда бірегей `/s/xxxxx` сілтемесін жасау

## Ескерту
Бұл MVP. `data/sites.json` — жергілікті сақтау. Нағыз көпқолданушылы нұсқада PostgreSQL/Supabase сияқты база және тұрақты storage қолдану керек.
